# mr-chen-rui's clone of *SpaceWars*

Inspired by Spacewar, however, having projectiles makes the training of the AI much harder.

A game (?) made for the *Player 2* YSWS run by **Hack Club**. Sadly, the program ended before I could submit :(

The objective of the game is to pilot your ship to a target destination using the *least* fuel possible. 
This is made interesting by the fact that there is a neutron star at the center, providing a gravity well.
